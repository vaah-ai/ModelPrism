# Step 3: Create Feature Branch

Invoke `git` MCP server:
- Switch to `develop`, pull latest.
- Create branch `feature/{{TASK_ID}}-short-description` from `develop`.
- If branch exists, switch to it and confirm up to date with `develop`.

> **Important:** Always create feature branches from the `develop` branch only — never from `main` or any other branch.
